Features

Everything you need, every morning

Four data modules working together to deliver your personalized daily briefing.

⛅

Weather Free

Current conditions, 3-day forecast, sunrise/sunset. Powered by wttr.in with Open-Meteo fallback. Works on all platforms.

📅

Calendar Pro

Today's events from macOS Calendar.app. Filter by calendar, configure lookahead days, and see event details at a glance.

📰

News Pro

Headlines from your RSS/Atom feeds. Add any feed, set per-source limits, and stay informed — all processed locally.

✅

Reminders Pro

Due reminders from macOS Reminders.app. Filter by list, see priorities and due dates. Never miss a task.
